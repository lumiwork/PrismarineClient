# PrismarineClient

PrismarineClient is a modern Minecraft client focused on performance, customization, and an intuitive user experience.

## ✨ Features

- Fabric support
- Modern in-game UI
- Performance optimizations
- Modular architecture
- Easy integration with Fabric mods
- Discord Integration

## 📖 About

PrismarineClient is built to provide a clean and responsive Minecraft experience while remaining fully compatible with the Fabric modding ecosystem. It includes custom in-game interfaces and is designed to be lightweight, fast, and easy to extend.

## 🚀 Goals

- High performance
- Clean and modern design
- Stable Fabric compatibility
- Easy customization
- Continuous development

## 📦 Requirements

- Java 21 or newer (IT IS VERY IMPORTANT SINCE I FOUND BUGS)
